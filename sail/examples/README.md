# Demonstration release

[example-model](../../example-model/) demonstrates native SAIL SRM v2 technical evidence. Its model content is a placeholder fixture. It is not a trained SAI system, a benchmark result, or a safety-certified release.

- `example-aibom.json` is the native SAIBOM build-input object. Its historical filename is retained for compatibility. It is not an SPDX document.
- `example-attestation.json` supplies explicit reports and explains the fixture's evaluation limitations. No passing result is generated by signing.
- `example-public-key.json` is the publisher public descriptor for the committed demonstration. It is outside the bundle so the CLI can consume it as an explicit test trust anchor. This placement alone does not independently authenticate a publisher.

Verify from the repository root:

```bash
PYTHONPATH=sail/src python -m sail verify ./example-model \
  --trusted-key sail/examples/example-public-key.json
```

The expected technical result is `VERIFIED`, with a matching supplied key. The demonstration key is a test fixture, not evidence of the maintainer's real-world identity.

## Regenerate locally

Regeneration replaces the demonstration signature and public fixture key. It does not preserve the previous signing identity. Use a fresh private-key location outside the model and never commit that private key:

```bash
sail_demo_keys="$(mktemp -d)"

PYTHONPATH=sail/src python -m sail keygen --alg ed25519 \
  --out "$sail_demo_keys/publisher.key" \
  --public-out sail/examples/example-public-key.json

PYTHONPATH=sail/src python -m sail sign ./example-model \
  --model-name sail-example --model-version 1.0.0 --tier T1 \
  --alg ed25519 --key "$sail_demo_keys/publisher.key" \
  --issuer the-open-reality-initiative-demo \
  --contact https://github.com/Grigaliunas/SAIL-GPL/security/advisories/new \
  --policy-url https://github.com/Grigaliunas/SAIL-GPL/blob/main/SECURITY.md \
  --saibom sail/examples/example-aibom.json \
  --attestation sail/examples/example-attestation.json \
  --trusted-key sail/examples/example-public-key.json

PYTHONPATH=sail/src python -m sail verify ./example-model \
  --trusted-key sail/examples/example-public-key.json
```

The date defaults to the current UTC time. The model card and demonstration inputs must exist before signing. The reporting and policy URLs identify the intended repository channels; offline verification does not establish that private reporting is enabled or that an operator will respond.

The generated native inventory is `example-model/srm/saibom.json`. Any old `aibom.spdx.json` should be removed as part of migration before signing. The full file inventory binds the model card, explicit reports, SAIBOM, and disclosure policy under the release signature.

For a production release, replace all demonstration content with actual model inventory, evaluation evidence, disclosures, and independently authenticated trust anchors. See [the toolkit guide](../README.md).
